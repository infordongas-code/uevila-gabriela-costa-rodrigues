# Portfólio — Uevila Gabriela

## Como abrir no VS Code
1. Extraia o arquivo ZIP para uma pasta.
2. Abra o Visual Studio Code.
3. Vá em **File > Open Folder** e selecione a pasta `portfolio_uevila_gabriela`.
4. Abra `index.html` no navegador. Se tiver a extensão **Live Server**, clique em **Go Live**.

## Personalização
- Edite textos, habilidades e projetos em `index.html`.
- Altere cores, fontes e estilos em `style.css`.
- O menu responsivo e o ano do rodapé são controlados por `script.js`.
- No botão de contato, substitua `seuemail@exemplo.com` pelo seu e-mail.
- Os projetos são exemplos visuais; troque-os pelos seus trabalhos reais.
